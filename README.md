# 公司定制面试准备 Skill

结合脱敏简历、目标 JD 和可追溯公司信息准备面试的 AI Skill。

它会区分公司事实、岗位推理、待核验与未查到信息，再生成简历证据、自我介绍提纲、可能问题、连续追问和反问清单。它不会编造公司事实或候选人经历，也不提供真实面试中的隐蔽实时辅助。

## 安装到 Codex

    Use $skill-installer to install the skill from:
    https://github.com/lilixinxinai/company-tailored-interview-prep-skill/tree/main/skills/company-tailored-interview-prep

安装后调用：

    $company-tailored-interview-prep

请提供一份脱敏简历、完整 JD、准确公司名称和官网，以及已知的面试轮次、形式和语言。

## 输出

1. 准备边界
2. 来源覆盖
3. 公司与岗位情报
4. 简历证据地图
5. 一分钟自我介绍提纲
6. 高概率问题主题与追问
7. 反问清单
8. 模拟训练方案
9. 待核验与禁用说法
